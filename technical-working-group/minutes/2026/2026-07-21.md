- Remaining work is to move Windows and macOS to Qt6 (linux is complete). Conda packages are building and working but standalone packaging still has some problems.

### Skipping jobs and required jobs

- When steps of jobs are skipped, they appear as though they have passed. It would be cleaner if we could skip whole jobs so they show as skipped on GitHub, rather than internally skipping steps of jobs. This is blocked by our required jobs list.
- The new model would define the required jobs as whatever jobs have been chosen to run by our filters.

### Mantid 7.0 features

- Upgrading to Qt6
- Swapping the default instrument view to the new instrument view (keeping the current one as 'legacy')
- Upgrading to Python 3.13
- Removed the `quasielasticbayes` library and associated algorithms
- ISIS ConvertToMD continuous rotation epic

- Instrument 1.0 access layers are being deprecated
- Deprecate the `mantid-developer` conda package (developers to move to `pixi`)
